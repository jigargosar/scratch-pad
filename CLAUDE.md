# scratch-pad

Quick scratch, no friction. Quick write, quick find.

- No filename to invent, no folder to choose.
- No wondering whether it saved. Crash resistant.
- Full versioned history.
- Sync through several storage options.
- Plain text, or any other language or format.
- When needed, multiple blocks in one file, each with its own language.
- Navigation and editing stay consistent across blocks, the same way they work on a file.
- Snippet execution. Inline math evaluation.

Progressive disclosure throughout. The interface is simple and the basic path is the whole surface until you reach for more. Power appears only when needed, where it is needed. Never reach for it and the app stays basic forever.

Deliberately ambitious. Not all of it ships soon.

## Facts

- The app has never been launched since the simplification rewrite. To check it by hand: `pnpm dev`, type a few characters, then read `.data/scratch.md`.
- No test runner is installed and no test has ever run.

Current state, next steps, features and non-obvious facts live in `docs/roadmap.md`.
